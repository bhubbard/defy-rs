Three Core Gameplay Subsystems

Engineered from ground up with data-oriented structures, cache locality, and Bevy ECS schedule compatibility.

Wanted Level System

defy_rs::wanted

Progressive 1-to-6 stars system with score thresholds, unit compositions, dynamic roadblock probabilities, and line-of-sight cooldown decay.

  • 1 Star: Cruiser patrol with peaceful arrest attempt
  • 3 Stars: SWAT Enforcers, spikes, helicopter air support
  • 6 Stars: Military martial law, Rhino tanks, shoot-on-sight
  • Out-of-sight search radius bubble with progressive star decay

Crime & Witness Pipeline

defy_rs::crime

Multi-modal sensory detection combining directional visual FOV cones with omnidirectional acoustic sound propagation.

  • Auditory radius: gunfire (60-90m), blast explosions (200m)
  • Witness shock delay before dialing 911
  • Silenceable witnesses cancel reports before dispatch triggers
  • Categorized severities: Minor, Moderate, Felony, Capital

Bystander AI Archetypes

defy_rs::npc

Rich bystander reactions determined by psychological personality traits and proximity to gunfire, vehicle theft, and melee assaults.

  • Coward: Cowers or flees screaming upon loud sounds
  • AverageCitizen: Raises hands at gunpoint, calls 911 when safe
  • Aggressive: Fights back against melee assaults and carjackings
  • ArmedVigilante: Conceals pistol, returns fire during shootout

Getting Started

Integrate defy-rs in Minutes

Plug directly into your Bevy ECS systems or custom engine tick.

src/main.rs 
use glam::Vec3;
use defy_rs::{
    WantedLevelSystem, WantedStatus, WitnessSystem,
    CrimeEvent, CrimeType, NpcEntity, NpcPersonality, NpcContext, ThreatStimulus,
};

fn main() {
    // 1. Initialize Wanted Level System
    let mut wanted = WantedLevelSystem::default();
    wanted.add_crime_score(150, Vec3::ZERO); // 1 Star Triggered
    println!("Current Wanted Stars: {}", wanted.stars);

    // 2. Register Witness and 911 Call Countdown
    let mut witnesses = WitnessSystem::new();
    witnesses.register_witness(
        1,
        Vec3::new(5.0, 0.0, 5.0),
        CrimeEvent {
            crime_type: CrimeType::VehicleTheft,
            perpetrator_id: 100,
            location: Vec3::ZERO,
            timestamp_sec: 0.0,
            is_direct_police_view: false,
        },
        3.0, // 3.0s call timer
    );

    // Player intimidates witness before report finishes:
    let silenced = witnesses.silence_witness(1);
    assert!(silenced);

    // 3. Simulate Bystander Reaction
    let mut citizen = NpcEntity::new(10, Vec3::ZERO, NpcPersonality::AverageCitizen);
    citizen.update(&NpcContext {
        threats: vec![ThreatStimulus {
            source_id: 100,
            position: Vec3::new(0.0, 0.0, 3.0),
            is_gunfire: false,
            is_aimed_at_me: true,
            is_melee_attack: false,
        }],
        delta_time: 0.016,
    });
    println!("Citizen reaction: {:?}", citizen.reaction); // HandsUp
}
